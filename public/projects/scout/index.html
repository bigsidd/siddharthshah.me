I built an AI analyst that answered a revenue team's questions in Slack

A Slack bot built with Claude Code that read the data warehouse and affiliate offer feeds, and answered with how sure it was and one next step.

Role
Sole builder: design, code, evals
Built with
Claude Code, Slack, about 40 tools
Checks
About 235 smoke tests before each deploy

OutcomeSix colleagues asked it about 105 questions, and one of its payout recommendations went live in an affiliate network.

Our revenue team already worked in Slack, so Scout lived there: @mention it in any channel and ask. When a colleague said a projected RPM looked wrong, Scout agreed and called its own number a model artifact.

Questions were what people came for. The scheduled posts, a morning pulse and weekly digests, drew almost no replies. I turned off an hourly monitor and removed a daily reminder that had gone about 137 days without a single answer.

The calls

No number without context
Every data answer carried a confidence line, and Scout said "Thin data" when too little sat behind an answer.
Ask before guessing
If a publisher name could mean two accounts, it asked which one you meant.
Take the better forecaster
When a stronger forecaster turned up, I folded its method into Scout the same day and kept it behind a backtest gate, out of users' sight.
Evals from real questions
Fifteen questions colleagues had actually asked decided which tool answered what, and which tools must not fire.
