I built the script and dashboard that put brand offers inside mobile games

MoMoney lets a game studio add a small offers unit at a natural break, like a cleared level, where players see a few brand perks to claim or save.

Role
Hosted script, dashboard, demos, contracts
Built with
Claude Code
Formats
Sheet, card, embed, interstitial

OutcomeMy offer units shipped in an Android game on Google Play.

A cofounder started the product and a games engineer built both in-house games. I built the offer layer in the shooter, early features in the puzzle game, the hosted script, the dashboard work, the demos and the default contracts.

Before selling it, I proposed putting the product in our own puzzle game.

The calls

A script, not an API
Studios wouldn't hand-integrate an API just to try a format. So I built one script they paste in. It handles several formats and reports no-fill and error reasons back to the game.
The advertiser leads
I closed my own change that added a sponsored tag and a terms line. The advertiser's logo and name should lead each unit.
Respect the player
In the unit rebuild I started in November, close shows from the first frame, save never leaves the game, and an offer that won't fit is skipped, not truncated.
Paper that fits
I drafted the default publisher agreement and insertion order, then negotiated changes for the first studio that signed.
